# 🚨 CrisisSync AI

AI-powered emergency detection and response system that identifies critical situations like fire, medical emergencies, and security threats in real-time.

## 🌟 Features
- 🚨 Panic Button for instant alert triggering
- 🎤 Voice-based emergency input
- 🤖 AI-based emergency classification
- 📊 Live Admin Dashboard
- 🔔 Alert notifications with sound
- 🌙 Dark mode support

## 🛠️ Tech Stack
- HTML
- CSS
- JavaScript
- Node.js (Backend - Local version)
- Gemini AI (for smart classification)

## 🚀 How It Works
User inputs emergency → AI analyzes → Emergency type detected → Dashboard updates → Suggested actions shown
